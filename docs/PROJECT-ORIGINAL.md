# 啤酒前沿 · Beer Frontier

一个可以直接部署的中文静态网站，用价格与可比口碑生成帕累托前沿。没有后台、数据库、登录、API Key、远程字体、CDN库或自动爬虫。

**开始使用：**离线看 `standalone.html`；正式部署把 **`dist/` 的内容**作为网站根目录。`dist/` 已生成，无需 npm install 或编译。

## 本次研究覆盖与边界

研究快照：2026-09-27，中国大陆零售参考场景。

- 42个候选条目，含原清单、新增代表性酒款，以及需要确认具体产品的名称占位条目。
- 27款有BeerAdvocate原始用户均分及样本数。
- 12个有总价、件数、容量和出处的价格样本；其中包含3个已知历史样本和1个SKU有歧义的样本，二者默认排除。
- 49条来源登记。部分价格页面无法直接读取全文，来源明确标记为搜索索引。
- **默认可进入数值比较的是7款，不是42款。** 默认前沿有4个节点：百帝王、保拉纳、罗斯福8、罗斯福10。该结论只是这些参考样本的数学结果，不是全市场购买推荐或当前售价承诺。

维森的71.3元起样本存在“原味浑浊/水晶白”描述歧义，未当作无条件有效报价。暴龙王的27.2元为2024年历史促销，没有伪装成当前便宜价格。国产喜力、国产朝日没有直接套用进口版评分。

它不是“所有啤酒”的完整数据库，更不保证实时性。未找到可确认的价格、评分或产品身份，就保留空值并解释原因，而不是用目标价假装市场价。

## 功能

价格口径可切换：折合500ml、每瓶/罐、整单。500ml只是价格分母，不是饮用量建议；整箱折合单件价并不表示可单独购买。

支持预算滑块、风味大类、具体风格、ABV上限、最低评分样本、全局与同风格前沿。全局比较可能受风格偏好影响；同风格模式按**具体风格名称**分组，不把所有小麦或所有黑啤混为一类。

前沿与预算阶梯实时计算。没有新增评分优势就不强行继续划分“更高档”。另有“带预算问价”区域：基于当前对手推导入围竞争界线，明确不是市场价。

每款的详情包括评价归纳、争议/取舍、编辑判断的适合人群、原包装报价换算、样本数、原始来源，以及未进入前沿的原因。

可以填写实付总价、件数、单件容量，也可以填写自己喝过后的0–5分。个人分模式独立于社区分，不混算。对比清单最多3款。个人数据保存在浏览器localStorage，支持导出和校验导入JSON，不同步到服务器。

## 本地打开

直接双击 `standalone.html`，使用现代浏览器。它包含全部CSS、JS与研究数据，无需网络即可渲染。浏览器若限制本地文件的存储，计算仍可使用，但个人记录请及时导出。

也可进入此目录后：

```bash
python -m http.server 8080 --directory dist
```

然后打开 `http://localhost:8080`。这是本地预览方式，不建议用Python开发服务器直接承担公网生产服务。

## 交给部署Agent

直接告诉Agent：

```text
解压后先阅读 AGENTS.md。将 dist/ 内容作为静态网站根目录，
接入我现有的域名、HTTPS和Web服务器。不要运行 seed.py，不要创建后端，
不要添加账号系统、统计代码或第三方CDN。完成后检查预算筛选、酒款弹窗、
个人报价重算、JSON导入导出、手机布局。保持数据出处与非实时价格提示。
```

没有指定域名、证书或服务器路径时，由Agent结合你现有部署环境处理。包中没有任何云端凭据，也未进行公网部署。

### Nginx

`deploy/nginx.conf` 是静态服务配置示例。普通VPS应由Agent替换 `root` 和 `server_name`，不要直接覆盖已有站点。已有反向代理时只需转发到静态服务端口，或直接把 `dist/` 挂为站点目录。HTTPS配置交给已有证书管理流程。

### Docker（可选，不是必需）

```bash
docker build -t beer-frontier .
docker run --rm -p 8080:80 --name beer-frontier beer-frontier
```

镜像构建需要拉取Nginx基础镜像；浏览器使用网站不需要外部资源。生产环境可以自行将基础镜像固定为经过验证的版本或摘要。

## 修改研究数据

唯一人工维护源为 `data/beers.json`。不要只改 `data/data.js` 或 `dist/`，它们都是派生产物。

```bash
node scripts/build.mjs
node --test tests/core.test.cjs
```

等价命令为 `npm run build`、`npm test`。无需安装依赖；构建脚本使用Node标准库。构建后同步生成 `data/data.js`、`standalone.html`、`SOURCES.md`、`dist/`。

`data/schema.json` 描述数据结构。`scripts/seed.py` 仅保留本次研究快照的生成过程，**日常维护不要运行**，因为会覆盖已编辑的数据。新增或核验数据应直接改JSON，更新核对日期，并同步修改基线测试中写死的快照计数。

新价格必须同时有总价、包装件数、单件容量、币种、出处、日期状态。无法确认运费或优惠资格必须说明。`historical`用于已知旧样本；发布日期未知不代表新近。`ambiguous`用于商品版本/规格尚有歧义，不能为了让图更满而解除。

```text

```

## 测试与验证限制

15项Node纯函数/数据测试通过。18项界面/交付检查通过，包含390px、768px、1440px布局、弹窗、预算重算、对比、表格、来源、JSON导入导出、单文件渲染及静态HTTP文件响应。

测试环境的受管Chromium禁止所有URL导航，因此**浏览器渲染使用真实单文件HTML的DOM注入，存储使用测试专用内存Storage接口替身**。HTTP静态文件响应另外通过Python标准库核验。真实域名导航、真实浏览器localStorage跨会话持久化，以及完整生产HTTPS部署未在此环境验证。测试报告如实记录这些限制；测试替身不会进入交付网页。

部署后应做一次真实浏览器验收，尤其是域名、缓存、移动端和数据保存。网站没有隐藏网络请求，但点击原始来源会正常离开本站访问第三方网站。
